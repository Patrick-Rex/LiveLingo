# LiveLingo.App

共享 Avalonia 表现层，仅引用 Core；使用 CommunityToolkit.Mvvm 和 AXAML 编译绑定，平台操作由中立契约交给宿主。界面规范见 [UI-DESIGN.md](UI-DESIGN.md)。

主窗口分为“实时翻译、历史记录、设置”三个一级页面，默认960×760、最小760×600 DIP。实时页只保留采集应用、启停、运行摘要、字幕显隐与当前会话正文；更改模型可直接进入运行环境。历史记录页阅读本地会话及正在记录的最新内容，当前投影不代表全部内容已落盘。设置按常规、字幕外观、运行环境和快捷键四个内部分组组织；运行环境的六个路径位于高级折叠区，支持系统文件/目录选择与显式存在检查。路径检查不启动服务，也不替代开始翻译时的模型完整性校验。

主界面共享语义主题资源位于 `Themes/DesktopTheme.axaml`，由控制窗加载，支持跟随系统、浅色和深色。设置中的字幕预览只使用合成文字，不读取真实历史或启动采集。主题和字幕外观即时生效并自动保存；历史保留期显示7天、30天、90天和永久，默认30天，持久化以0表示永久；与模型、语言、路径和快捷键一起在停止后明确应用或撤销。应用操作仅位于设置页；其他页面显示待应用提示及直达入口。存在未应用输入时禁止开始翻译，切换页面保留草稿。

SnapshotPump 合并最新完整快照，并在执行回调时核对会话、单调序号与停止屏障。实时页显示有效双语正文，普通行显示草稿、更新中、已定稿及待译/失败短状态，版本信息只放在可展开详情。浮窗默认显示最近两个非空块并在布局完成后滚动到末尾。手动回看暂停跟随，按 SegmentKey 保留正在阅读的两块，仍从权威快照更新修订并移除撤销或空块；“回到最新”及新会话恢复跟随，重新锁定不强制恢复。旧译文标为待更新，不修改模型原文。

浮窗右上角的小锁使用40×40 DIP独立命中区域，无障碍名称和提示随锁态变化；锁定正文避让图标，移除运行状态、版本和长说明。解锁时显示单行拖动、显示语言与 A− / A+ 工具；Ctrl+滚轮调整字号，四边四角仍可缩放，回看时才显示“回到最新”。中文字号16–64 DIP，原文按18:28同比例缩放。锁定按钮使用从属窗口，40 DIP高度适配Windows对原生窗口最小高度的限制，随字幕窗关闭。位置、尺寸、字号、背景和显示模式自动保存；回看状态不落盘。

历史页通过Core历史契约读取当前数据目录的 `history` 库，支持按应用搜索会话、按原译文筛选和分页。运行中可复制、导出TXT或Markdown，结束后可确认删除选中条目、选中会话或清空已结束历史。复制和导出无条目选择时处理整场，有选择时只处理固定身份集合；保存交互出现前冻结文本，取消不写出文件。正文选择跨页保留，单页时隐藏无效翻页操作。目录切换拒绝旧库迟到结果，关闭取消并等待交互，但存储生命周期由宿主管理。

视图模型互斥启停与手动保存。自动保存与明确应用经同一互斥入口提交，自动保存只合并主题和字幕字段到最后成功持久化的配置，不带入未确认模型、路径、快捷键或保留期；失败提供重试，退出前冲刷末次外观调整。加载失败的原文件不被自动覆盖，明确应用成功后恢复自动保存。历史保存失败显示全局反馈和重试入口。测试使用 Headless，真实点击穿透、非激活与多屏缩放需额外原生检查。命令见 [测试说明](../../tests/README.md)。
