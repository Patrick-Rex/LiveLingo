# LiveLingo.App

共享 Avalonia 表现层，仅引用 Core；使用 CommunityToolkit.Mvvm 和 AXAML 编译绑定，平台操作由中立契约交给宿主。

SnapshotPump 合并最新完整快照，并在执行回调时核对会话、单调序号与停止屏障。控制窗显示有效双语历史，浮窗默认显示最近两个非空块并在布局完成后滚动到末尾。手动回看暂停跟随，按 SegmentKey 保留正在阅读的两块，仍从权威快照更新修订并移除撤销或空块；“回到最新”及新会话恢复跟随，退出布局模式不强制恢复。旧译文标为待更新，不修改模型原文。

控制窗和浮窗布局工具条提供双语／仅中文／仅原文即时切换，仅改变浮窗正文可见性，状态与待译提示保留，历史和推理不变。显示模式随字幕外观自动保存；回看状态不落盘。

视图模型互斥启停与保存。浮窗右上角唯一的“解锁拖动／锁定位置”按钮始终可用，控制窗移除重复开关；解锁后显示拖动条、四边四角缩放光标及字幕工具；A− / A+ 或 Ctrl+滚轮可在运行中即时调整双语字号（中文16–64 DIP，原文按18:28同比例缩放），普通滚轮保留长句浏览。锁定后正文恢复穿透，锁定按钮使用从属窗口维持独立命中区域，随字幕窗关闭；位置、尺寸、字号和背景即时生效，连续调整稳定后自动保存。控制窗按会话历史、字幕外观、模型与路径、快捷键分区，主操作和手动保存栏固定可见。模型、路径和快捷键停止后手动保存或撤销，有待确认运行配置时禁止开始。字幕保存与手动保存经同一互斥入口提交，自动保存只合并字幕字段到最后成功持久化的运行配置；失败显示并允许重试，退出前冲刷最后调整。加载失败的原文件不被自动覆盖，须明确手动保存恢复。测试使用 Headless，真实点击穿透需额外原生检查。命令见 [测试说明](../../tests/README.md)。
