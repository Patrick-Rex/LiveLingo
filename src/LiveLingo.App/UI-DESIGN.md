# 桌面界面规范

本规范对应已确认的桌面体验改造，沿用 Avalonia FluentTheme 与编译绑定。目标是让日常翻译、档案管理和低频配置各有明确入口。

## 视觉与状态

- 主窗口默认跟随系统，可选择浅色、深色。语义资源区分页面、表面、正文、次级正文、边框、强调与错误；主题相关颜色使用 DynamicResource。
- 间距采用4/8/12/16/24 DIP，正文14、说明12、页面标题24 DIP；字幕字号保持16–64 DIP，默认28。正文支持中日文字形回退与换行。
- 主按钮只用于当前主要行动；次要操作使用普通按钮，删除使用明确文案和确认。控件保留Fluent焦点、悬停、按下、禁用状态。
- 加载显示进行中并抑制重复提交；错误提供原因和下一步；空列表说明如何产生内容。不用颜色单独表示状态。
- 图标按钮具备提示和无障碍名称。字幕小锁的独立命中区为40×40 DIP，适配Windows原生窗口的最小高度；其他紧凑图标按钮至少32×32 DIP。

## 页面结构与信息层级

| 页面 | 从上到下的结构 | 状态与操作 |
| --- | --- | --- |
| 实时翻译 | 标题与主操作 → 采集应用与状态 → 双语内容 | 启停、显隐；未应用配置提供设置入口 |
| 历史记录 | 标题与刷新 → 会话列表/正文详情 → 分页 | 查找、复制、导出；结束后确认删除 |
| 设置 | 常规、字幕外观、运行环境、快捷键四个内部分组 | 即时偏好自动保存；应用/撤销固定在设置页，六个路径放在运行环境的高级折叠区 |

主窗口默认960×760、最小760×600 DIP，正文区域受可用高度约束。列表使用有界视口与虚拟化；设置正文单独滚动，操作区可达。

## 字幕两种状态

- 锁定：双语正文＋右上角小锁。正文穿透，小锁单独命中；保留必要的草稿、待更新状态。
- 调整：紧凑拖动区＋语言与字号控件＋锁定入口。边缘负责缩放，正文负责阅读；回看时提供回到最新。
- 常规运行状态与版本诊断留在主窗口或详情，不常驻浮窗。字幕背景不随主窗口主题改变。

## 保存、记录与反馈

主题和字幕外观即时生效并自动保存；模型、语言、路径、快捷键和历史保留期停止后明确应用或撤销。切页保留草稿，未应用输入会阻止开始翻译，其他页面提供设置入口。运行草稿不会被外观自动保存带入。字幕预览仅用合成文字；路径检查只报告格式与存在性，实际引擎状态由启动报告。

每次开始至停止形成会话，双语正文保存在当前数据目录的 `history` 子目录；默认保留30天，可选7/90天或永久。运行中可查阅、复制和导出TXT/Markdown，结束后允许单条、多选、整场与清空删除，确认框说明范围，清空保留活动会话。复制、导出无条目选择时处理整场，有选择时固定所选身份；导出在保存对话框前冻结内容，取消不生成文件。选择跨正文页保留，只有多页才显示翻页控件。历史未完整保存持续提示并可重试，切换数据目录不搬迁旧记录。
