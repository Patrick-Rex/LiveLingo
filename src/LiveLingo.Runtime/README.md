# LiveLingo.Runtime

组合有界 Channels、单写入者状态机、连续音频缓存、重叠识别、本地或 OpenAI 兼容 API 识别/翻译和 MAF 工作流，不依赖 UI 或 Windows API。

SubtitlePipeline 管理字幕处理与积压，使用 Core 的短句划分逐句翻译，连续无标点长段也能单独回填每个短句，过期或错配结果由身份与版本屏障拒收。语义块修订时保留能一对一匹配的已译短句，按新句序调度剩余短句。窗口内的自动换行只影响排版。会话可选用一份原文与译名对照表。桌面宿主只传入与翻译目标语言相符的词表，API 翻译会话还会跳过仅限本地使用的词表。整句精确匹配直接提交指定译文，该句的模型调用数为零。句中匹配时，本地和 API 提示附上本句命中的词条，保留完整原文。桌面直播的开放段最多 30 秒，持续讲话或衔接失败时保留已识别范围，改用最长 6 秒的相邻短段。最短 2 秒的重试仍不完整时标记未识别范围，继续处理其后音频。常规文件回放按原策略在对齐失败时最多扩窗至 120 秒；截断生成不进入字幕。取消与模型冷启动都有共同时间预算。

启用直播积压恢复时，未识别音频达到默认 600 秒上限便取消旧调用，登记从最后接受的识别终点到触发包末尾的缺口，再以新采集代次处理下一包。此前接受的原文及已返回译文保留在同场历史。文件回放保留原有超限终止行为。历史记录器按采集代次与范围去重，同一场最多逐项列出 128 处积压缺口，更多缺口以提示说明。正常结束仍标记为“已结束”，最终运行故障记为“中断”，存储缺失按已有“部分保存”规则处理。

首次启动先等待模型就绪，再开始采集。全本地直播在新语段首个常规窗口最多等待 1 秒；同一安静尾部取得稳定结果后恢复常规刷新。私有 Ollama 在会话内保持所选模型驻留，停止时回收。会话中发生采集或模型恢复时，流水线继续接收当前采集代次的音频，写入现有的有界缓存，模型就绪后从保留范围继续推理。若再次重置或停止，先取消并等待在途的模型重置退出。

当常规推进仍落在失败的识别终点，新增至少一个刷新间隔的音频后，可缩短本次推进距离，先在最后可信终点之后一个刷新间隔处尝试衔接。每次尝试仍须有真实音频重叠且通过完整性与归属校验。待执行识别有多次更新时，最近观察到的安静尾部优先保留一次，用于复核句尾。工作队列按实际未处理范围计算压力，长语义块内已识别的音频不重复计入积压。

DesktopSettingsStore 以同目录原子替换保存版本化设置，损坏文件保留；可接收宿主提供的首次安装默认设置，仅文件不存在时使用，不覆盖已有配置或改变损坏恢复。旧版设置缺少 DisplayMode 时默认双语，缺少模型来源时仍默认双本地。读取旧版缺失语言或 `auto` 的设置时使用日语，单纯读取保留原文件。应用新选择后，下场会话使用新语言，重启程序仍会保留。存储层原子保存完整设置，App 层分别管理字幕自动保存和运行设置手动保存，非法枚举值拒绝加载且保留原文件。WaveReplaySource 提供连续 PCM 转换和按墙钟回放。测试及构建见 [测试说明](../../tests/README.md)。

JsonTranslationHistoryStore 使用 Core.History 中立契约，在已提交的 `DataPath/history` 下按会话和采集代次保存版本化 JSON，不保存音频，也不需要数据库。记录器快速接收权威完整快照，由唯一后台写入任务串行提交同目录临时文件并原子替换；同代次修订与撤销替换当前版本，采集恢复封存前一代次，真实重复按身份保留。内存每场最多保留 257 个代次、每代次 4,096 条、合计 12,288 条快照条目，与现行流水线的恢复和字幕容量上限配套；当前存储实例最多保留 8 场活动、保存失败或部分保存的会话，不无限积压。超过历史记录容量时继续翻译，但会话永久标记“部分保存”，成功写入、重试和重启都不会清除已发生的内容缺失；重试只能恢复仍在内存中的待写内容。

历史保存状态独立报告，磁盘失败不会终止翻译，后续修订继续更新有界内存，用户可明确重试；停止冲刷最后版本。分页列表只读取摘要，所选正文按需加载，活动会话读取及导出包含尚未落盘的固定内存快照。上次未正常结束的会话显示中断，损坏文件保留并报告。TXT/Markdown 导出包含应用、会话身份、识别语言、翻译模型、起止时间和记录状态，保留草稿、修订及译文待更新状态，不伪造跨采集代次的连续时间轴。

支持已停止会话的单条、多选、整场删除及清空已结束记录；活动会话拒绝定向删除且清空会保留它。尚未成功保存的停止会话可整场删除并撤销后续重试，删除后的状态通知在全部存储锁外发布，单条删除需先重试保存。7/30/90 天及永久保留由宿主在启动、会话结束、每日调用清理；清理使用结束时间，中断记录优先使用摘要记录的最后保存时间，旧摘要缺少该字段则从文件修改时间恢复，跳过活动会话。存储实例固定历史根，切换 DataPath 需在停止后切换实例，旧目录不自动搬迁；显式验证必须使用独立数据根。

Qwen 收到会话指定的语言名 `Chinese`、`English`、`Japanese` 或 `Korean`。OpenAiAsrService 将最多 120 秒的窗口编码为内存 PCM16 WAV，在标准音频转写请求中显式发送对应的 `language` 值 `zh`、`en`、`ja` 或 `ko`。Ollama 和 OpenAiTranslationService 都使用会话选定的源语言和翻译目标，支持中文、英语、日语和韩语之间的翻译，默认输出简体中文。中文译中文时保留原意并将繁体转为简体，其他同语输入保留原文措辞和含义。本地模型预热沿用会话的翻译方向。API 翻译使用非流式 Chat Completions，输出预算为 2048 token。共享 HTTP 边界最多读取256KiB响应、拒绝重定向、传递取消并覆盖响应体读取超时，不把服务错误正文写入异常。LocalPipelineModels 兼容原本地入口并按每阶段来源组装，API 不预热、不请求模型列表；取消不承诺远端停止计费。历史保留会话选定的原文语言、翻译目标语言、模型来源和实际正文。API 地址与 Key 不写入档案。
