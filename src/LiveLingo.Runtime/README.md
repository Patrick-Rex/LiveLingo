# LiveLingo.Runtime

组合有界 Channels、单写入者状态机、连续音频缓存、重叠识别、Ollama 翻译和 MAF 工作流，不依赖 UI 或 Windows API。

SubtitlePipeline 管理字幕处理与积压，过期结果由身份屏障拒收。正常识别窗口30秒，对齐失败时默认最多回退到120秒；截断生成不进入字幕。取消与模型冷启动都有共同时间预算。

DesktopSettingsStore 以同目录原子替换保存版本化设置，损坏文件保留；旧版设置缺少 DisplayMode 时默认双语，存储层原子保存完整设置，App 层分别管理字幕自动保存和运行设置手动保存，非法枚举值拒绝加载且保留原文件。WaveReplaySource 提供连续 PCM 转换和按墙钟回放。测试及构建见 [测试说明](../../tests/README.md)。

JsonTranslationHistoryStore 使用 Core.History 中立契约，在已提交的 `DataPath/history` 下按会话和采集代次保存版本化 JSON，不保存音频，也不需要数据库。记录器快速接收权威完整快照，由唯一后台写入任务串行提交同目录临时文件并原子替换；同代次修订与撤销替换当前版本，采集恢复封存前一代次，真实重复按身份保留。内存每场最多保留 257 个代次、每代次 4,096 条、合计 12,288 条快照条目，与现行流水线的恢复和字幕容量上限配套；当前存储实例最多保留 8 场活动、保存失败或部分保存的会话，不无限积压。超过历史记录容量时继续翻译，但会话永久标记“部分保存”，成功写入、重试和重启都不会清除已发生的内容缺失；重试只能恢复仍在内存中的待写内容。

历史保存状态独立报告，磁盘失败不会终止翻译，后续修订继续更新有界内存，用户可明确重试；停止冲刷最后版本。分页列表只读取摘要，所选正文按需加载，活动会话读取及导出包含尚未落盘的固定内存快照。上次未正常结束的会话显示中断，损坏文件保留并报告。TXT/Markdown 导出包含应用、会话身份、识别语言、翻译模型、起止时间和记录状态，保留草稿、修订及译文待更新状态，不伪造跨采集代次的连续时间轴。

支持已停止会话的单条、多选、整场删除及清空已结束记录；活动会话拒绝定向删除且清空会保留它。尚未成功保存的停止会话可整场删除并撤销后续重试，删除后的状态通知在全部存储锁外发布，单条删除需先重试保存。7/30/90 天及永久保留由宿主在启动、会话结束、每日调用清理；清理使用结束时间，中断记录优先使用摘要记录的最后保存时间，旧摘要缺少该字段则从文件修改时间恢复，跳过活动会话。存储实例固定历史根，切换 DataPath 需在停止后切换实例，旧目录不自动搬迁；显式验证必须使用独立数据根。
