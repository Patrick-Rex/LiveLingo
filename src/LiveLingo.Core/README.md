# LiveLingo.Core

平台无关的音频区间、目标身份、会话状态机、字幕版本和桌面服务契约，不引用 Windows、Avalonia 或 MAF。

字幕归约器校验会话、采集代次和源版本，拒绝迟到结果；真实重复按身份及出现次序保留。语义块身份、音频范围和定稿标准不因短句翻译而改变。识别原文按句末、换行或子句停顿划分，连续无标点长段也能按阅读长度分句。修订时沿用原文完全匹配的连续前缀译文。待重译的位置可展示已有原译对并标明上一版，只有新版本译文参与定稿。对齐必须能确定上下文归属，不能通过硬切句或拼补模型文字隐藏失败。桌面契约提供设置校验和工作区布局计算；SubtitleDisplayMode 定义双语、仅中文和仅原文显示，旧设置缺省双语，未知模式拒绝加载。

History 提供会话摘要、采集代次内条目身份、固定正文快照和独立保存状态，以及记录、分页查询、删除、文本导出、保留期清理契约。记录器接收权威字幕快照，也可登记直播积压导致的未识别范围。范围使用所属采集代次内的 16 kHz 半开采样区间。存储与恢复实现位于 Runtime。

测试位于 tests/LiveLingo.Core.Tests，统一命令见 [测试说明](../../tests/README.md)。

DesktopMaintenance 定义带组件标识的环境初检结果、路径发现、用户触发的依赖安装及更新服务中立契约，不引用 Velopack、网络或平台进程 API；具体安装与检查位于 Windows 宿主。

ModelBackend 为识别和翻译提供各自独立的本地/API 选择，OpenAiApiSettings 使用 base_url、api_key、model。DesktopSettings 只校验所选来源，未使用的 API 默认空配置，旧设置保持双本地；数据和缓存约束始终有效。HistorySessionInfo.AsrModel 可选保存新会话的识别来源和模型，旧记录不追补。
