# LiveLingo.Core

平台无关的音频区间、目标身份、会话状态机、字幕版本和桌面服务契约，不引用 Windows、Avalonia 或 MAF。

字幕归约器校验会话、采集代次和源版本，拒绝迟到结果；真实重复按身份保留。对齐必须能确定上下文归属，不能通过硬切句或拼补模型文字隐藏失败。桌面契约提供设置校验和工作区布局计算；SubtitleDisplayMode 定义双语、仅中文和仅原文显示，旧设置缺省双语，未知模式拒绝加载。

History 提供会话摘要、采集代次内条目身份、固定正文快照和独立保存状态，以及记录、分页查询、删除、文本导出、保留期清理契约；不引用文件选择器、数据库或 UI。记录器接收权威字幕快照，存储与恢复实现位于 Runtime。

测试位于 tests/LiveLingo.Core.Tests，统一命令见 [测试说明](../../tests/README.md)。
